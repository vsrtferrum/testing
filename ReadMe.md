# Чек-лист проверки выбора ингредиентов

## Требование

Пользователь может добавлять и удалять ингредиенты у базовой пиццы.

Доступные ингредиенты:

| Ингредиент | Цена за порцию, руб. |
|---|---:|
| Пепперони | 60 |
| Ветчина | 70 |
| Грибы | 50 |
| Лук | 30 |
| Оливки | 40 |
| Бекон | 80 |

Ограничения:

- одного ингредиента можно добавить только 1 порцию;
- минимальное количество ингредиентов - 1;
- максимальное количество ингредиентов - 5.

## Чек-лист

### 1. Отображение ингредиентов

- [ ] Отображаются все доступные ингредиенты.
- [ ] Названия ингредиентов отображаются корректно.
- [ ] Цены ингредиентов соответствуют требованиям.
- [ ] Для каждого ингредиента доступны кнопки добавления и удаления.
- [ ] При открытии формы отображается корректное начальное состояние базовой пиццы.

### 2. Добавление ингредиентов

- [ ] Можно добавить Пепперони.
- [ ] Можно добавить Ветчину.
- [ ] Можно добавить Грибы.
- [ ] Можно добавить Лук.
- [ ] Можно добавить Оливки.
- [ ] Можно добавить Бекон.
- [ ] После добавления ингредиент появляется в составе пиццы.
- [ ] После добавления стоимость пиццы увеличивается на цену ингредиента.
- [ ] Один и тот же ингредиент нельзя добавить более одного раза.
- [ ] После добавления ингредиента кнопка его добавления блокируется.
- [ ] Кнопки добавления остальных ингредиентов остаются активными.
- [ ] Ингредиенты можно добавлять в любом порядке.
- [ ] Можно добавить 5 разных ингредиентов.
- [ ] После добавления пятого ингредиента все кнопки добавления блокируются.
- [ ] Шестой ингредиент невозможно добавить.

### 3. Удаление ингредиентов

- [ ] Можно удалить каждый добавленный ингредиент.
- [ ] После удаления ингредиент исчезает из состава пиццы.
- [ ] После удаления стоимость пиццы уменьшается на цену ингредиента.
- [ ] После удаления кнопка добавления этого ингредиента снова становится активной.
- [ ] Удалённый ингредиент можно добавить повторно.
- [ ] После удаления одного ингредиента из пяти кнопки добавления становятся активными.
- [ ] Нельзя удалить не добавленный ингредиент.
- [ ] При отсутствии ингредиентов кнопка удаления заблокирована.
- [ ] При наличии ингредиентов кнопки удаления доступны для добавленных ингредиентов.

### 4. Минимальное количество ингредиентов

- [ ] Нельзя завершить заказ без ингредиентов.
- [ ] При отсутствии ингредиентов отображается нотификация: **«Необходимо добавить хотя бы один ингредиент»**.
- [ ] Текст нотификации отображается без ошибок и опечаток.
- [ ] После добавления хотя бы одного ингредиента нотификация не отображается.
- [ ] После удаления последнего ингредиента снова применяется ограничение минимального количества.
- [ ] После удаления последнего ингредиента кнопка удаления блокируется.

### 5. Максимальное количество ингредиентов

- [ ] Можно добавить не более 5 ингредиентов.
- [ ] Нельзя добавить шестой ингредиент.
- [ ] После добавления 5 ингредиентов все кнопки добавления заблокированы.
- [ ] Кнопки удаления при этом остаются доступными.
- [ ] После удаления ингредиента кнопки добавления становятся активными.
- [ ] После повторного добавления количество ингредиентов не превышает 5.

### 6. Проверка стоимости

- [ ] Добавление Пепперони увеличивает стоимость на 60 руб.
- [ ] Добавление Ветчины увеличивает стоимость на 70 руб.
- [ ] Добавление Грибов увеличивает стоимость на 50 руб.
- [ ] Добавление Лука увеличивает стоимость на 30 руб.
- [ ] Добавление Оливок увеличивает стоимость на 40 руб.
- [ ] Добавление Бекона увеличивает стоимость на 80 руб.
- [ ] Стоимость корректно пересчитывается при добавлении нескольких ингредиентов.
- [ ] Стоимость корректно пересчитывается при удалении ингредиентов.
- [ ] При добавлении пяти ингредиентов сумма рассчитывается корректно.
- [ ] Повторное добавление одного ингредиента не увеличивает стоимость повторно.

### 7. Комбинации и граничные случаи

- [ ] Добавить один ингредиент и удалить его.
- [ ] Добавить два ингредиента и удалить один из них.
- [ ] Добавить четыре ингредиента, удалить один и добавить другой.
- [ ] Добавить пять ингредиентов и удалить их по очереди.
- [ ] Добавить ингредиенты в обратном порядке.
- [ ] Многократно нажать кнопку добавления одного ингредиента.
- [ ] Многократно нажать кнопку удаления одного ингредиента.
- [ ] Быстро нажать кнопки добавления и удаления.
- [ ] Проверить, что количество ингредиентов и стоимость не становятся отрицательными или некорректными.
- [ ] Проверить корректность состояния кнопок после каждого изменения состава.

### 8. Визуальные проверки

- [ ] Заблокированные кнопки визуально отличаются от активных.
- [ ] Нотификация отображается в предусмотренном месте.
- [ ] Добавленные ингредиенты визуально отличаются от доступных для добавления.
- [ ] Состав пиццы обновляется без перезагрузки страницы.
- [ ] Текст, цены и элементы управления не перекрываются.
- [ ] Интерфейс корректно отображается на поддерживаемых разрешениях экрана.
